# doodle-lab 기획 정리

## 1. 출발점
- 참고 영상: 날아람(@fly_aramm) "ai 그림으로 용돈 벌기 도전 4일차" — "5분 낙서로 100만원 벌기"
- 방식: 낙서 → AI로 파스텔 색연필 일러스트화 → 미리캔버스 디자인허브에 디자인 요소로 등록 → 다운로드·인쇄당 로열티
- 영상 설명란에 프롬프트 전문 공개(파스텔 색연필, 외곽선 없음, 투명 PNG, 글자 없음, 독립 소품)

## 2. 현실 점검
- 수익 구조는 실제로 존재. 후기: 2024년 약 410만원 → 2025년 상반기 약 140만원으로 감소
- 단가 하락: 건당 25원 → 3~5원짜리 증가, 단가는 작가가 정할 수 없음
- 영상 프롬프트가 공개돼 같은 스타일이 몰릴 위험 → **차별화가 핵심**
- AI 생성물은 업로드 시 AI 체크 필수 / 수익은 프리미엄 승인 요소만
- 결론: 그대로 따라 하면 레드오션, **태블릿 직접 그림 + 빈 주제 공략**이면 승산 있음

## 3. 툴 컨셉
1. 시장 조사 — 미리캔버스에서 수요와 손그림 경쟁 정도 파악
2. 시안 제안 — "이걸 그려라" 브리프 (주제, 소품 목록, 팔레트, 차별점)
3. 직접 그리기 — 태블릿
4. 업로드·다듬기 — 배경 제거, 소품별 자동 분리, 여백, 규격
5. 내보내기 — 투명 PNG / JPG, 제목·태그 자동 생성, 플랫폼별 프리셋

형태: **웹(나중에 PWA)** 추천 — 태블릿·PC 모두 사용, 앱스토어 심사 없음

## 4. 시장 조사 진행 상황
- 데이터: 미리캔버스 공개 인기 일러스트 검색어 697개 × 키워드별 상위 약 60개 요소의 태그·색상·썸네일
- 지표: 수요(sitemap 순서, 인기순이라는 가정은 미검증), 손그림 비율, 대형 스톡 비율, 작가 수 → 기회 점수
- 중간 결과
  - 손그림 작가 1,383명, 상위 10명 점유 18% → 분산된 시장
  - 손그림 태그: 손그림 > 스케치 > 수채화 > 낙서 > 드로잉 > 파스텔 > 색연필(145)
  - 크리스마스: 선명한 빨강·초록 플랫 벡터 + 글자 요소 위주, 파스텔 색연필은 드묾 → 기회
  - 일러스트·말풍선·꽃은 손그림 경쟁 치열

## 5. 법적 검토
- robots.txt에서 /illust 경로 허용, 사이트맵으로 키워드 직접 공개, 로그인 없는 공개 페이지만, 1초 간격
- 이용약관에 크롤링 명시적 금지 조항 없음. 관련 조항 c(타인 정보) · f(복제·배포) · p(운영 방해) 모두 회피
- 진짜 위험은 **베끼기(조항 i, 저작권)** → 썸네일은 포화도 파악용, 시안은 빈자리 공략
- 마무리 조치: 분석 후 원본 데이터·썸네일 시트 삭제, 통계(report.json)만 보관, 작가명 제외
- help.miricanvas.com은 Cloudflare 봇 확인으로 접근 불가 → 우회하지 않음

## 6. 판매처
| 판매처 | 방식 | 수익 | 적합도 |
|---|---|---|---|
| 미리캔버스 디자인허브 | 디자인 요소 | 다운로드당 로열티 | ★★★ |
| OGQ 마켓 | 네이버 블로그·카페 스티커 | 최대 70%(2024 보도) | ★★★ |
| 아이디어스 / 마플샵 | 굿노트 스티커·PNG 세트 | 직접 가격 / 마플샵 수수료 13.75%+3.52% | ★★★ |
| Adobe Stock | 해외 스톡, 투명 PNG | 33% | ★★☆ |
| Etsy | 클립아트 묶음 | 수수료 약 10% 안팎 | ★★☆ |
| Canva | 요소 신청 중단(템플릿만) | — | 제외 |
| 망고보드 | 기여자 판매 제도 못 찾음 | — | 참고용 |

전략: 한 번 그린 세트를 여러 곳에 판매(독점 조건 확인 필수)
- 1순위 미리캔버스 + OGQ, 2순위 세트 판매(아이디어스/마플샵), 3순위 해외(Adobe/Etsy)

## 7. 다음 단계
1. 수집 완료 → 전체 기회 순위
2. 상위 후보 썸네일 비교 → **시안 3~5개** (주제, 소품 목록, 팔레트, 차별점)
3. 원본 데이터 삭제
4. 시안으로 직접 그려보기 → 반응 확인
5. 웹 툴 MVP: 업로드 → 배경 제거·소품 분리 → 플랫폼별 PNG/JPG + 태그
6. 이후: 판매 수익 대시보드, 시즌 주제 캘린더
