# doodle-lab

태블릿 손그림 → 미리캔버스 디자인허브 판매용 요소를 만드는 걸 돕는 툴.
(가계부 · 쏠쏠셈과 무관한 별도 프로젝트)

## 흐름

1. **시장 조사** — 미리캔버스 공개 일러스트 검색 페이지에서 수요(인기 검색어)와 경쟁(손그림 요소 비율, 작가 수)을 수집
2. **시안 제안** — 수요는 있는데 손그림 경쟁이 적은 주제로 "이걸 그려라" 브리프 생성
3. **직접 그리기** — 태블릿
4. **업로드 · 다듬기** — 배경 제거, 소품별 자동 분리, 여백 · 규격 맞춤 (웹)
5. **내보내기** — 투명 PNG / JPG + 제목 · 태그

## 폴더

- `research/crawl_miricanvas.py` — 수집 (공개 페이지, 1초 간격)
- `research/analyze.py` — 기회 점수 계산 → `research/data/report.json`

## 미리캔버스 규격 메모

- PNG 요소 700~9800px, SVG 최대 6000px · 150KB
- AI 생성물은 업로드 시 AI 체크 필수
- 수익은 프리미엄 라이선스 승인 요소만
