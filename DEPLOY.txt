우리 가계부 다시 띄우기 (GitHub 없이)
=====================================
가계부 데이터는 Firebase(ih-money 프로젝트)에 그대로 있습니다. 화면(웹사이트)만 다른 곳에 올리면 됩니다.

방법 A. Firebase Hosting (추천) — 주소: https://ih-money.web.app
  데이터가 있는 같은 Firebase 프로젝트라 로그인 설정을 따로 안 해도 됩니다.
  PC에 Node.js(https://nodejs.org, LTS)가 있어야 합니다.
  1) 이 압축을 푼 money 폴더에서 터미널을 엽니다.
     - 맥: '터미널' 앱을 열고  cd  (뒤에 한 칸 띄우고) money 폴더를 창에 끌어다 놓은 뒤 엔터
     - 윈도우: money 폴더를 연 탐색기 주소창에  cmd  라고 치고 엔터 (PowerShell 말고 cmd가 오류가 적습니다)
  2) npm install -g firebase-tools
  3) firebase login        (가계부 Firebase를 만든 Google 계정으로 로그인)
  4) firebase deploy --only hosting
  5) 끝나면 https://ih-money.web.app 로 접속해서 로그인
  - 4)에서 호스팅 사이트가 없다는 오류가 나면: Firebase 콘솔 > 빌드 > Hosting > '시작하기'를 한 번 누른 뒤 4)를 다시
  - 맥에서 2)가 권한 오류(EACCES)로 실패하면: sudo npm install -g firebase-tools
  - 나중에 코드를 고치면 4)만 다시 하면 됩니다.

방법 B. Netlify Drop (프로그램 설치 없이 끌어다 놓기)
  1) https://app.netlify.com/drop 에 이 폴더(압축 푼 것)를 통째로 끌어다 놓기
  2) 생긴 주소(예: xxxx.netlify.app)를 복사
  3) Firebase 콘솔 > Authentication > 설정 > 승인된 도메인 > 도메인 추가 에 그 주소를 넣기
     (안 넣으면 Google 로그인이 막힙니다)

공통
  - Google Cloud 콘솔에서 API 키 사용처를 제한해 두었다면, 새 주소도 허용 목록에 추가하세요.
  - 샘플(데모) 화면은 주소 끝에 ?demo=1

자동 배포 (한 번만 설정)
  GitHub main 브랜치에 합쳐지면 .github/workflows/firebase-deploy.yml 이 자동으로 Firebase에 올립니다.
  처음 한 번, PC의 money 폴더에서:
    firebase init hosting:github
  - 저장소를 물으면  siw61001-prog/money
  - "build script" 를 물으면 N (빌드할 것이 없음)
  - "deploy when a PR is merged" 는 Y, 브랜치는 main
  - 이 과정에서 GitHub 비밀값 FIREBASE_SERVICE_ACCOUNT_IH_MONEY 가 자동 등록됩니다.
  - 이 명령이 money 폴더에 만든 .github 파일들은 GitHub에 올리지 않아도 됩니다 (저장소에 이미 있음).
  확인: GitHub 저장소 > Actions 탭에서 "Firebase 배포" 가 초록 체크면 성공.
