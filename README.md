# 우리 가계부

인원·혜미가 함께 쓰는 가계부 웹앱입니다. 수입·소비지출·고정비용·자산을 한 화면에서 입력하고, 사람별/통합 대시보드로 확인합니다.

- 상단에서 **통합 / 인원 / 혜미** 를 고르면 그 사람 기준으로 모든 화면이 바뀝니다.
- **내역 입력** 버튼으로 기록합니다. 통합 화면에서 입력하면 누구 내역인지 먼저 고릅니다.
- 고정비용 중 `저축`, `단기 적금` 분류는 지출이 아니라 **정기 저축**으로 집계합니다.
- 실제 저축 = 수입 − 고정비용 − 소비지출 (정기 저축 포함), 저축률 = 실제 저축 ÷ 수입.
- **매달 반복 결제는 “고정비용으로 처리할까요?”라고 묻습니다**: 같은 사람·같은 가게에서 비슷한 금액(±15%)이 두 달 이상 결제되면 묻고, ‘예’를 눌러야 고정비용으로 바뀝니다.
  - 일괄 등록 미리보기(전체/한 줄씩), 직접 입력 창, 내역 화면 위쪽(이미 저장된 소비지출) 세 곳에서 묻습니다.
  - ‘아니요’를 고른 가게는 다시 묻지 않습니다.
  - 장보기·식당·배달·커피·편의점(식비·외식·카페/간식)은 금액이 같아도 묻지 않습니다. 고정비용으로 쓴 적 없는 생활비·쇼핑·미용 등도 제외. 파일에 적힌 분류가 있으면 가게 이름보다 우선합니다(예: ‘배민클럽’이 구독료면 묻는다).
  - 한 달에 같은 금액이 여러 번 나오는 곳(뽑기, 주유 등)은 제외합니다.
  - 고정비용 분류는 이전에 쓴 고정비용 분류 → 이름(보험·관리비·적금·통신 등) → 통신/구독 순으로 정합니다.
- 내역 화면의 **‘지난달 고정비용 복사’** 로 매달 반복되는 구독·보험·저축을 한 번에 넣을 수 있습니다.
- 내역 > **엑셀 일괄 등록** 에서 양식(.xlsx)을 받아 여러 건을 적어 올리면 한 번에 등록됩니다.
  - 양식 열: 날짜 · 누구 · 구분(소비지출/고정비용/수입) · 분류 · 결제 수단 · 금액 · 메모
  - ‘누구’가 빈 줄은 등록 화면에서 고른 사람으로, ‘구분’이 빈 줄은 소비지출로 들어갑니다.
  - 올리기 전에 미리보기를 보여주고, 읽지 못한 줄은 행 번호와 이유를 알려줍니다.
  - 이미 있는 내역과 사람·날짜·구분·금액·메모가 같으면 중복으로 보고 건너뜁니다 (체크하면 함께 등록).
  - 예전 가계부 파일(수입/소비지출/고정비용 시트)도 그대로 올릴 수 있습니다.
  - **카드사 이용내역 엑셀**(.xlsx/.xls)도 양식 변환 없이 올릴 수 있습니다.
    - 위쪽 안내 문구를 건너뛰고 ‘이용일·가맹점명·이용금액’ 같은 머리글 줄을 자동으로 찾습니다. 합계 줄과 취소된 결제는 뺍니다.
    - 분류는 이전에 같은 가게로 입력한 내역 → 가게 이름 키워드(스타벅스·이마트·주유 등) 순서로 추정하고, 미리보기 표에서 바꿀 수 있습니다.
    - 카드 파일에는 사람 정보가 없으니 등록 화면에서 카드 주인을 고릅니다.
    - 같은 사람·날짜·금액의 내역이 이미 있으면(직접 입력한 것 포함) 중복으로 보고 건너뜁니다. 기존 내역 1건당 카드 내역 1건만 짝짓습니다.
    - 해외 결제(가맹점명에 `USD:22.00` 등)는 환율 차이를 감안해 같은 날 금액 3% 이내면 같은 결제로 봅니다.
    - 중복으로 걸린 결제에서 ‘가게 → 분류’를 배워 같은 가게의 다른 줄에 적용하고, 미리보기에서 한 줄을 바꾸면 같은 가게 줄이 함께 바뀝니다 (네이버페이 같은 결제대행사는 제외).
    - 확인한 형식: 현대카드 이용대금명세서(.xls, HTML 표), 직접 정리한 월별 내역표(‘9월’/‘10월’ 구역, 날짜 903·1002 형식, 분류·결제수단·메모 열)
    - 파일에 분류 열이 있으면 그 분류를 쓰고 가계부 분류로 맞춥니다 (마트장·배달음식→식비, 화장품→미용, 옷/쇼핑→쇼핑, 구독료→통신/구독).
    - 파일 이름에 사람 이름이 있으면(예: `가계부(혜미).xlsx`) 그 사람 내역으로 넣습니다.
- 설정 > **엑셀 가계부 가져오기** 는 처음 옮길 때 쓰는 기능으로, 자산 시트까지 읽고 다시 가져오면 이전 가져오기분을 교체합니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `index.html`, `css/style.css` | 화면 |
| `js/app.js` | 대시보드·내역·자산·설정 화면과 집계 |
| `js/store.js` | 저장소 (Firebase Firestore, 설정 전에는 브라우저 저장 데모 모드) |
| `js/import.js` | 엑셀(.xlsx) 가져오기 |
| `js/firebase-config.js` | Firebase 웹 앱 설정값 |
| `firestore.rules` | 두 사람의 Google 계정만 접근 허용하는 보안 규칙 |

빌드 과정이 없는 정적 사이트라 GitHub Pages에 그대로 올리면 됩니다.

## 배포 순서

### 1. Firebase 프로젝트 만들기
1. <https://console.firebase.google.com> 에서 **프로젝트 추가** (Google 애널리틱스는 꺼도 됩니다).
2. **빌드 > Authentication > 시작하기 > 로그인 방법 > Google** 사용 설정.
3. **빌드 > Firestore Database > 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)`, **프로덕션 모드**.
4. Firestore **규칙** 탭에 `firestore.rules` 내용을 붙여넣고, 두 이메일 자리를 실제 Gmail 주소로 바꾼 뒤 **게시**.
5. **프로젝트 설정(톱니바퀴) > 일반 > 내 앱 > 웹(</>)** 으로 앱 등록 → 나오는 `firebaseConfig` 값을 `js/firebase-config.js`에 붙여넣기.

### 2. GitHub Pages에 올리기
1. GitHub에서 새 저장소 생성 (예: `gagyebu`, Public).
2. 이 폴더에서:
   ```bash
   git remote add origin https://github.com/<아이디>/gagyebu.git
   git push -u origin main
   ```
3. 저장소 **Settings > Pages > Branch: `main` / `/ (root)`** 저장. 1~2분 뒤 `https://<아이디>.github.io/gagyebu/` 로 열립니다.
4. Firebase **Authentication > 설정 > 승인된 도메인** 에 `<아이디>.github.io` 추가.

### 3. 기존 데이터 옮기기
1. 배포된 주소에서 Google 로그인.
2. **설정 > 엑셀 가계부 가져오기** 에서 두 xlsx 파일을 함께 선택 → 파일별 주인 확인 → **가져오기**.
3. 다시 가져와도 ‘이전 엑셀 가져오기 데이터 교체’가 켜져 있으면 중복되지 않습니다 (직접 입력한 내역은 유지).

## 보안 메모
- `*.xlsx`, `*.json` 은 `.gitignore`로 막혀 있어 저장소에 올라가지 않습니다. 저장소에는 코드만 있습니다.
- `firebase-config.js`의 값은 공개되어도 되는 식별자입니다. 데이터 접근은 `firestore.rules`의 이메일 목록으로만 허용됩니다.
- 설정 > **JSON 백업 받기** 로 가끔 백업 파일을 받아 두세요.
