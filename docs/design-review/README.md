# 우리 가계부 — 디자인·편의성 검토용 설명서

이 문서는 다른 사람(또는 AI)이 코드를 열지 않고도 이 가계부 웹앱의 **화면 구조, 사용 흐름, 디자인 규칙**을 이해하고 **편의성과 디자인을 검토**할 수 있도록 정리한 것입니다. 화면 캡처는 `screens/` 폴더에 있고, 모두 가상의 샘플 데이터(지훈·수아)입니다.

> 검토를 맡은 분께: 맨 아래 **"검토 요청"** 절에 특히 봐 주었으면 하는 질문을 모아 두었습니다. 제안은 "무엇이 문제인지 → 왜 → 어떻게 바꿀지" 순서로, 우선순위(높음/중간/낮음)를 붙여 주시면 반영하기 쉽습니다.

## 1. 제품 개요

| 항목 | 내용 |
|---|---|
| 무엇 | 두 사람(부부·커플)이 함께 쓰는 개인 가계부 웹앱 |
| 누가 | 두 명. 개발자가 아닌 일반 사용자. 한국어 사용 |
| 주로 어디서 | **휴대폰(약 80%)**. 결제 직후 지출을 바로 적고, 저녁에 대시보드를 훑어봄. PC는 엑셀 일괄 등록·설정 정리할 때 |
| 핵심 목적 | ① 지출을 빠르게 기록 ② 이번 달 예산을 얼마나 썼는지 한눈에 ③ 매달 저축이 되는지 확인 ④ 지출 목표를 카톡으로 공유 |
| 성격 | 매일 쓰는 **작업용 도구**(대시보드·입력·목록). 꾸밈보다 빨리 읽히고 실수 없이 입력되는 것이 우선 |

### 용어
- **소비지출**: 식비·카페 등 그때그때 쓰는 돈 (예산 관리 대상)
- **고정비용**: 월세·보험·구독처럼 매달 나가는 돈. 그중 `저축`·`단기 적금` 분류는 지출이 아니라 **정기 저축**으로 계산
- **실제 저축** = 수입 − 고정비용 − 소비지출
- **통합**: 두 사람 합산 보기. 예산·저축 목표는 항상 두 사람 합산 기준
- **하위 분류**: 식비만 `외식·마트·편의점·배달음식`으로 한 번 더 나눔 (가게 이름으로 자동 추정)

## 2. 기술 구조 (간단히)

- 빌드 도구 없는 정적 웹앱: `index.html` + `css/style.css` + `js/*.js` (바닐라 JS, ES 모듈)
- 데이터: Google Firebase(Firestore). Google 계정 로그인, 등록된 두 계정만 읽고 쓰기 가능
- 호스팅: Firebase Hosting (`ih-money.web.app`)
- 그래프: Chart.js 4 (저장소에 포함). 엑셀 읽기: SheetJS (필요할 때만 불러옴)
- 화면은 JS가 문자열 템플릿으로 통째로 다시 그림 (프레임워크 없음). 데이터가 바뀌면 즉시 다시 그려짐
- 주소 끝에 `?demo=1`을 붙이면 로그인 없이 샘플 데이터로 열림 (이 문서의 캡처가 이 모드)

| 파일 | 역할 |
|---|---|
| `index.html` | 상단바, 탭, 대화상자(입력·자산·엑셀 등록·일괄 수정·공유) 뼈대, SVG 아이콘 |
| `js/app.js` | 모든 화면 그리기와 동작 (약 2,600줄) |
| `js/store.js` | 저장소 (Firebase / 데모) |
| `js/import.js` | 엑셀·카드사 명세서 읽기 |
| `js/sample.js` | 데모용 샘플 데이터 |
| `css/style.css` | 디자인 토큰과 모든 스타일 (약 560줄) |

## 3. 화면 구조 (정보 구조)

```
┌ 상단바 (항상 보임, 스크롤해도 고정) ───────────────────────┐
│ [곰 로고] 우리 가계부  [데모 모드]                [↑ 공유] │
│ [통합 | ● 지훈 | ● 수아]            [‹  2026년 11월  ›]    │
└────────────────────────────────────────────────────────────┘
  PC: 상단바 아래 탭 [대시보드 | 내역 | 자산 | 설정]
  휴대폰: 화면 아래 고정 탭바 (아이콘+글자 4개)
  오른쪽 아래 떠 있는 [+ 내역 입력] 버튼 (대시보드·내역 화면)
```

- **사람 선택(통합/지훈/수아)**: 모든 화면의 숫자가 그 사람 기준으로 바뀜. 단, 예산·저축 목표 비교는 항상 두 사람 합산
- **월 선택(‹ ›)**: 모든 화면이 그 달 기준. 가운데 월 이름을 누르면 이번 달로
- **공유 버튼**: 보고 있는 달의 지출 목표 문구를 만들어 복사·카톡 공유

### 3-1. 대시보드 (`screens/m-dashboard-*.png`, `d-dashboard-*.png`)
위에서부터 순서대로:

1. **요약 숫자 3개**: 수입 / 지출(고정+소비) / **실제 저축·저축률** ← 화면에서 유일하게 진한 초록 바탕으로 강조. 적자면 적갈색
2. **분류별 사용 현황**: 소비지출·예산 대비 %·남은 예산·이 속도면 월말 예상. 분류마다 "예산을 100%로 놓고 몇 % 썼는지" 가로 막대 그래프. 세로 점선 = 오늘 날짜 위치(막대가 선보다 길면 날짜보다 빨리 쓰는 중). 횟수 목표(예: 배달 6회)
3. **저축 목표**: 이번 달 실제 저축 / 월 목표, 연간 누적 / 연 목표, 이번 달 남은 돈
4. **사람별 비교** (통합 보기일 때만): 두 사람의 수입·고정·소비·저축·저축률. PC는 표, 휴대폰은 사람마다 블록
5. **이번 달 예산**: 전체 예산 중 사용액 막대 + "하루 ○○원까지 쓸 수 있어요". 분류별 막대(사용/예산, 남음·초과). 분류를 누르면 그 달 내역이 아래로 펼쳐지고, 내역을 누르면 수정 창
6. **최근 3개월 지출**: 월별 고정/소비 누적 막대 + 3개월 분류 합계
7. **일별 소비**: 날짜별 막대 + 이번 달 고정비용 목록
8. **연간 월별 흐름**: 월별 수입·지출 막대 + 실제 저축 선

PC는 2~3열 격자(12칸 그리드), 휴대폰은 한 줄로 쌓임.

### 3-2. 내역 (`screens/m-list-*.png`, `d-list-*.png`)
1. **"고정비용으로 처리할까요?"** (조건이 맞을 때만): 같은 가게에서 비슷한 금액이 2달 이상 나간 소비지출을 찾아 고정비용으로 바꿀지 물음. 3개까지 보이고 나머지는 "N개 더 보기"
2. **필터 도구**: 구분(전체/소비지출/고정비용/수입), 분류 선택, 메모 검색, 전체 선택, 그 달 합계, [엑셀 일괄 등록]
3. **날짜별 묶음 목록**: 날짜 머리(체크박스·날짜·그날 지출 합) 아래 한 줄씩 — 가게/메모, 분류 알약·누구·결제수단, 금액(지출 −, 수입 + 파랑). 줄을 누르면 수정, 체크하면 아래에 선택 막대(일괄 수정·삭제)

### 3-3. 자산 (`screens/m-assets-*.png`)
1. 순자산(강조) / 총 자산 / 부채 / 자산 구성
2. 사람별 순자산 막대
3. 순자산 추이 그래프(월별). 기록 없는 예전 달은 실제 저축으로 거꾸로 추정한 **점선**. 월별 표, "지난 달 기록 입력"
4. 자산·부채 목록 (누르면 수정 창)

### 3-4. 설정 (`screens/m-settings-*.png`)
1. **분류별 월 목표(예산)**: 원하는 항목만 추가. 항목마다 금액·횟수, ▲▼ 순서 (대시보드 표시 순서가 됨), 회색 글자 = 지난 3달 평균. "빈칸을 평균으로 채우기", 목표 저장
2. **월 저축 목표** (두 사람 합산)
3. **엑셀 가계부 가져오기** (처음 옮길 때)
4. **분류 관리**: 소비지출/식비 하위/고정비용/수입 분류, 결제 수단 — 쉼표로 구분한 글 상자
5. **분류 합치기**: 여러 분류의 내역을 한 분류로 옮김
6. **계정·백업**: JSON 백업 받기/복원, 로그아웃

### 3-5. 대화상자 (휴대폰은 아래에서 올라오는 시트, PC는 가운데 창)
- **내역 입력** (`screens/m-dialog-input.png`): 누구 → 구분 → 날짜·금액 → 분류(식비면 하위 분류) → 결제 수단 → 메모 → [저장 후 계속] [저장]
  - 금액 칸은 `12000+3500`처럼 더하기/빼기 가능, 오른쪽 **＋** 버튼(휴대폰 숫자 키패드엔 +가 없어서). 아래에 `= 15,500원` 표시
  - 분류를 고르면 아래에 "이 지출까지 포함하면 예산 ○○ 중 ○○ 사용" 안내
  - 메모(가게 이름)를 적으면 이전 기록으로 분류를 자동 추천, 매달 반복 결제로 보이면 "고정비용으로 처리할까요?" 안내
- **지출목표 공유** (`screens/m-dialog-share.png`): 자동 생성 문구(수정 가능) → [복사] / 휴대폰은 [카톡 등으로 보내기]. "묶음 바꾸기"로 항목 묶는 방식 설정
- **엑셀 일괄 등록**: 양식 받기 → 사람 고르기 → 파일 올리기 → 미리보기(중복 표시, 분류 수정) → 등록
- **자산 항목**, **선택한 내역 일괄 수정**

공유 문구 예시:
```
✨11월 지출목표: 150만원 이내로 쓰기
➡️ 137만원

1️⃣ 식비 50만원
-외식: 10만원
-마트: 15만원 ➡️ 2만원
...
```
(➡️ 뒤 = 남은 금액. 사용자가 원래 카톡으로 손으로 쓰던 형식을 그대로 재현한 것이라 형식 자체는 바꾸지 않는 것이 전제)

## 4. 디자인 시스템

### 방향
- 브랜드: 와사비 곰 캐릭터 로고 + 와사비 초록. 따뜻한 흰 바탕, 흰 카드
- 원칙: **숫자가 주인공**. 강조는 화면당 한 곳(실제 저축/순자산)만. 나머지는 차분하게
- 모든 글자색은 흰 바탕 대비 **4.5:1 이상**(WCAG AA)으로 맞춤. 12px 미만 글자 없음
- 글자용 색(진함)과 막대·그래프 채움용 색(밝음)을 분리

### 색
| 역할 | 토큰 | 값 |
|---|---|---|
| 바탕 | `--bg` | `#F6F5F0` |
| 카드 | `--surface` | `#FFFFFF` |
| 묶음 바탕(합계 상자 등) | `--surface-2` | `#EFEEE7` |
| 본문 글자 | `--ink` | `#1E221C` |
| 보조 글자 | `--muted` | `#5F5B52` (6.8:1) |
| 선 | `--line` | `#E4E2D9` |
| 막대 빈 부분 | `--track` | `#ECEAE2` |
| 주 버튼·링크 | `--accent` | `#3D7A2B` (흰 글자 5.2:1) |
| 강조 카드 | — | `#2F5E22` (적자 `#7E2F22`), 흰 글자 |
| 수입 (글자/채움) | `--income` / `--income-fill` | `#2C64A3` / `#4F86C6` |
| 지출 | `--expense` / `--expense-fill` | `#B93C2C` / `#DD6B5A` |
| 저축·여유 | `--saving` / `--saving-fill` | `#3A7529` / `#5C9A44` |
| 주의(80%↑ 또는 날짜보다 빠름) | `--warn` / `--warn-fill` | `#8F5A05` / `#D9962B` |
| 고정비용 그래프 | `--fixed-fill` | `#8A93A1` |
| 사람 색 | `--p1` / `--p2` | `#4F86C6` / `#D9789A` |

예산 상태 색: 여유 = 초록, 주의 = 주황(80% 이상이거나 날짜 진행보다 15%p 이상 빨리 씀), 초과 = 빨강.

### 글자
- 글꼴: Pretendard Variable (한글), 숫자는 고정폭 숫자(tabular-nums)
- 크기 단계: 12 · 13 · 15(본문) · 17(카드 제목) · 22(숫자) · 28(큰 숫자). 휴대폰 본문 14.5
- 무게: 본문 400, 라벨 600, 숫자·제목 700

### 간격·모양
- 간격 4px 단위: 4 · 8 · 12 · 16 · 20 · 24 · 32
- 카드: 흰 바탕, 모서리 16px, 옅은 그림자 하나(테두리 없음), 안쪽 여백 20px(휴대폰 16px)
- 알약(분류 표시): 모서리 6px, 기본은 중립 회색, 수입=파랑, 고정=회청, 저축=초록 옅은 바탕
- 버튼: 완전 둥근 알약형. 주 버튼만 초록 채움, 나머지는 흰 바탕+선
- 아이콘: 직접 그린 SVG, 선 굵기 1.8 통일 (이모지·유니코드 기호 사용 안 함)

### 반응형 (기준 720px, 960px)
- 960px 이하: 카드 격자 → 한 줄
- 720px 이하(휴대폰): 탭이 아래 고정 탭바로, 입력 버튼은 동그란 + 하나, 대화상자는 아래 시트, 표는 줄마다 블록으로 쌓임, 예산 줄은 "이름·금액" 윗줄 + 막대 아랫줄, 터치 영역 최소 40px

## 5. 주요 사용 흐름

1. **지출 기록 (가장 자주)**: 휴대폰 → 아래 + 버튼 → 사람(지난번 선택 기억)·소비지출(기본) → 금액 → 분류 → 저장. 연속 입력은 [저장 후 계속]
2. **이번 달 상태 확인**: 대시보드 첫 화면 → 실제 저축 카드 → 분류별 사용 현황 막대 → 예산 카드에서 분류 눌러 내역 확인
3. **목표 공유**: 상단 [공유] → 문구 확인·수정 → 복사 또는 카톡
4. **카드 명세서 한 번에 넣기**: 내역 → 엑셀 일괄 등록 → 파일 → 미리보기에서 분류 고치기 → 등록
5. **예산 정하기**: 설정 → 분류별 월 목표 → 항목 추가 → 금액(평균 참고) → 순서 → 저장

## 6. 이미 알고 있는 점 / 의도한 결정

의도한 것 (바꾸자는 제안은 이유가 분명할 때만):
- 실제 저축 카드는 월초(월급 전)에 적자로 적갈색이 되는 일이 많음 — 사실을 그대로 보여주는 것이 의도
- 공유 문구 형식은 사용자가 원래 쓰던 카톡 형식
- 예산·저축 목표는 사람 화면에서도 두 사람 합산 기준
- 사용자는 둘뿐이라 회원가입·권한 화면은 없음

알고 있는 문제 (아직 안 고침):
- 금액 칸에 `12,000+3,500+800`처럼 길게 적으면 칸 안에서 앞부분이 잘려 보임 (결과 `= 합계`는 아래에 표시됨)
- 수입이 아주 적은 달(월초)에는 사람별 저축률이 `-4214%` 같은 의미 없는 숫자로 나옴
- 설정 화면이 휴대폰에서 매우 길다 (한 줄로 6개 카드)
- 대시보드 카드가 8개로 많다 — 무엇을 접거나 뺄지 판단이 필요
- 데모 모드의 설정 안내 문구에 개발자용 설명(`firebase-config.js`)이 보임
